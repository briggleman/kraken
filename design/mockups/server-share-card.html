Server share card

What a shared server link turns into when it is posted in a Discord channel, and the page a friend lands on when they tap it. Discord builds the card from tags in the page head: a text half (og:site_name, og:title, og:description, and theme-color for the side bar) and a 1200×630 og:image the Panel renders over the spec's own game art. Discord caches what it fetched, so every image is stamped with the time of its reading.

In the channel

Text inside the image can't be selected or copied, so the join details are also in the description. The description is plain text: it can be selected on desktop, and a long press copies it on a phone. Tapping the link opens the share page below, which has a copy button for each value.

The share page

The page at /s/{token} is the same reading as the card, laid out for a phone held by someone about to join. Each join value has its own copy button. Copy all puts every value on the clipboard in the order the game's connect screen asks for them, ready to paste into a DM. The password is masked on screen so a shared screen or a screenshot doesn't expose it. Copying works without revealing it.

How a game is joined comes from its spec. Valheim and Palworld join by address. Windrose joins by invite code, so its card has no address. A server with no password shows no password row at all, rather than an empty value.

Unlike the embed, this page respects revocation. Once a link is revoked, the page returns 404, while anything already rendered into a Discord message stays there.

ElementSourceRule
Side bar<meta name="theme-color">running · stopped · unreachable. Same three readings as the chip.
Headlinespec nameThe game is the big type; the server's own name is the label above it, the way a node name sits above a server on the fleet deck.
Embed titleog:titleThe server's display name, so the blue link line and the image headline say different things.
Game artspec banner_urlThe Steam library hero every bundled spec already carries. Fades out under the text and toward the floor, cooled so the gold stays the only warm light. Greyscale when stopped. A spec with no banner, or a Panel with no outbound internet, renders the plain water column.
Join valuesa new spec join blockNames which values a player needs: address (public host + game port) or invite_code (a setting), plus the setting that holds the join password. Admin passwords are never eligible.
Passwordopt-in per linkOff by default. Once a password is in an embed, Discord keeps the image and description; revoking the link removes only the share page. Changing the password is the only real revocation, and the setting says so.
Descriptionog:descriptionGame · state · players on the first line, the join values on the second. The copyable text in Discord.
As-of stamptime of the last readingAlways shown. Discord can redisplay a cached card, and the stamp keeps it honest.
